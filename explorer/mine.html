Setup Instructions

1

Open Terminal & go to Downloads

Open your terminal and navigate to the folder where the file was downloaded:

cd ~/Downloads
2

Download & make executable

If you already clicked the Download button above, just make it executable. Otherwise download via terminal:

# Download (skip if you used the button above)
curl -LO https://github.com/pureinkart-tech/pichain/releases/latest/download/pichain-miner-linux-x86_64

# Make it executable
chmod +x pichain-miner-linux-x86_64
3

Generate a wallet

./pichain-miner-linux-x86_64 --keypair wallet.json --generate-keypair

This creates wallet.json with your keypair. Keep this file safe!

4

Start mining

./pichain-miner-linux-x86_64 \
  --keypair wallet.json \
  --rpc-url https://pichain.net \
  --profile desktop

Profiles: laptop (2 threads) | desktop (half cores) | server (all cores)

Alternative: Build from Source

Produces the fastest possible binary optimized for your exact CPU. Typically 10-20% faster than pre-built binaries.

Prerequisites: Git, a C compiler (gcc/clang), and basic build tools. 
# Step 1: Install build tools (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y build-essential pkg-config libssl-dev git

# For Fedora/RHEL:
# sudo dnf install gcc openssl-devel git

# For Arch:
# sudo pacman -S base-devel openssl git

# Step 2: Install Rust (skip if you have it)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Step 3: Clone and build
git clone https://github.com/pureinkart-tech/pichain.git
cd pichain
cargo build --release -p pichain-miner

# Step 4: Generate wallet
./target/release/pichain-miner --keypair wallet.json --generate-keypair

# Step 5: Start mining
./target/release/pichain-miner \
  --keypair wallet.json \
  --rpc-url https://pichain.net \
  --profile desktop
Prerequisites: Xcode Command Line Tools are required. Without them, the build will fail with "exit status 69" or linker errors. 
# Step 1: Install Xcode Command Line Tools
xcode-select --install

# If you see "You have not agreed to the Xcode
# license agreements", run this and accept:
sudo xcodebuild -license

# Step 2: Install Homebrew (skip if you have it)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Step 3: Install Rust (skip if you have it)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Step 4: Clone and build
git clone https://github.com/pureinkart-tech/pichain.git
cd pichain
cargo build --release -p pichain-miner

# Step 5: Generate wallet
./target/release/pichain-miner --keypair wallet.json --generate-keypair

# Step 6: Start mining
./target/release/pichain-miner \
  --keypair wallet.json \
  --rpc-url https://pichain.net \
  --profile desktop
Common macOS issues:
• "exit status 69" — Run sudo xcodebuild -license and accept
• "xcrun: error: invalid active developer path" — Run xcode-select --install
• Linker errors — Make sure Xcode CLT is installed: xcode-select -p should show a path
Prerequisites: You need Visual Studio Build Tools with the C++ workload. Without this, Rust cannot link native code. 
# Step 1: Install Visual Studio Build Tools
# Download from: https://visualstudio.microsoft.com/visual-cpp-build-tools/
# During install, select "Desktop development with C++"
# This provides the MSVC compiler and Windows SDK

# Step 2: Install Git for Windows
# Download from: https://git-scm.com/download/win

# Step 3: Install Rust
# Download rustup-init.exe from: https://rustup.rs
# Run it and follow the prompts (defaults are fine)

# Step 4: Open a NEW PowerShell window, then:
git clone https://github.com/pureinkart-tech/pichain.git
cd pichain
cargo build --release -p pichain-miner

# Step 5: Generate wallet
.\target\release\pichain-miner.exe --keypair wallet.json --generate-keypair

# Step 6: Start mining
.\target\release\pichain-miner.exe `
  --keypair wallet.json `
  --rpc-url https://pichain.net `
  --profile desktop
Common Windows issues:
• "link.exe not found" — Install Visual Studio Build Tools with "Desktop development with C++"
• "cargo not recognized" — Close and reopen PowerShell after installing Rust
• SmartScreen warning — Click "More info" → "Run anyway"

Miner Configuration

Fine-tune your miner for your hardware.

# Performance profiles (choose one)
--profile laptop    # 2 threads, gentle on battery
--profile desktop   # Half your CPU cores
--profile server    # All CPU cores
--profile max       # All cores + large batches

# Limit CPU usage (combine with any profile)
--max-cpu 50        # Cap at 50% CPU

# Manual fine-tuning
--threads 8         # Exact thread count
--digits-per-batch 2000  # Digits per proof

# Check your earnings
curl https://pichain.net/api/v1/account/YOUR_ADDRESS
