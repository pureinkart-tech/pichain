Mine PI by Computing PI

PIChain rewards miners for computing hexadecimal digits of π using the BBP algorithm. No GPUs required. No special hardware. Rewards scale with your compute power — everyone earns proportionally.

1

Install Rust & Build the Miner

The miner is written in Rust. Install Rust if you don't have it, then clone and build:

# Install Rust (skip if you already have it)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Clone PIChain and build the miner
git clone https://github.com/pichain/pichain.git
cd pichain
cargo build --release -p pichain-miner

# The binary will be at ./target/release/pichain-miner
2

Create a Wallet

Generate a new mining wallet. This creates a keypair file — keep it safe!

./target/release/pichain-miner --keypair wallet.json --generate-keypair

# Output:
#   Address:    0x1a2b3c4d...
#   Saved to:   wallet.json
#   Keep this file safe!

Connect & Start Mining

Point your miner at the PIChain RPC node:

http://YOUR_NODE_IP:8314 
# Start mining with your chosen profile
./target/release/pichain-miner \
  --keypair wallet.json \
  --rpc-url http://YOUR_NODE_IP:8314 \
  --profile server
The miner will auto-claim from the devnet faucet if your balance is zero. Mining rewards are credited directly to your wallet on every accepted proof.
5

Fine-Tune (Optional)

Override profile defaults for precise control:

# Custom thread count and batch size
./target/release/pichain-miner \
  --keypair wallet.json \
  --rpc-url http://YOUR_NODE_IP:8314 \
  --threads 8 \
  --digits-per-batch 1500 \
  --concurrent-batches 2

# Limit CPU to 50% (great for mining while working)
./target/release/pichain-miner \
  --keypair wallet.json \
  --rpc-url http://YOUR_NODE_IP:8314 \
  --profile desktop \
  --max-cpu 50
6

Monitor Your Earnings

Check your balance and the network mining stats:

# View your account balance
curl http://YOUR_NODE_IP:8314/api/v1/account/YOUR_ADDRESS

# View network mining stats
curl http://YOUR_NODE_IP:8314/api/v1/mining/status

Or visit the Mining Dashboard in your browser for real-time stats.
